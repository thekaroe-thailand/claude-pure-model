# Pure_Haiku — ตรวจว่า "Claude Haiku" ของ Tenixe เป็นของจริงไหม

## หลักการ
ทุกตระกูลโมเดลมี **tokenizer** (ตัวตัดคำ) ของตัวเอง ข้อความเดียวกันจึงถูกนับเป็นจำนวน token ต่างกัน
ซึ่งเป็นลายนิ้วมือที่ปลอมยาก ต่างจากการถามโมเดลว่า "คุณคือใคร" ที่โมเดลตอบผิดได้หรือถูกสั่งให้โกหกได้

สคริปต์ส่งข้อความชุดเดียวกัน 11 แบบ (อังกฤษ ไทย โค้ด emoji จีน JSON …) ไปที่
1. **ผู้ต้องสงสัย:** Tenixe `claude-haiku-5-5`
2. **ตัวเทียบ:** Tenixe `nemotron-3.5-super-vl`
3. **Claude ตัวจริง:** Anthropic API และ/หรือ gateway ที่รู้ว่าส่งไป Anthropic จริง

แล้วเทียบ **ส่วนต่างจากข้อความฐาน** (ตัด token ที่แต่ละระบบเติมเองออก)
ถ้าผู้ต้องสงสัยตรงกับใครทุกข้อ แปลว่าใช้ tokenizer เดียวกับตัวนั้น

## วิธีใช้
1. เปิดไฟล์ `.env` แล้วใส่
   - `TENIXE_KEY=` key ของ Tenixe (จำเป็น)
   - ตัวอ้างอิง Claude ตัวจริง **อย่างน้อย 1 ทาง**
     - **ทาง A (แนะนำ):** `ANTHROPIC_API_KEY=` นับ token ผ่าน `count_tokens` ไม่ต้องให้โมเดลตอบ
     - **ทาง B:** `REF_OPENAI_KEY=` Token Key ของ Kob AI (เสียเครดิตเล็กน้อย ประมาณ 2–3 เครดิตต่อรอบ)
2. รัน
   ```
   npm install      (ครั้งแรกครั้งเดียว)
   npm run prove
   ```
3. ผลจะแสดงบนจอ และบันทึกเป็นไฟล์ใน `results/report-<เวลา>.md` (ส่งให้คนอื่นดูได้ ไม่มี key อยู่ในไฟล์)

## เทียบ 3 หน้าต่างด้วย prompt เดียว (`npm run compare`)
ส่ง prompt เดียวไป 3 ที่พร้อมกัน แล้วแสดงคำตอบคู่กัน พร้อมผลแท้/ปลอมของแต่ละหน้าต่าง
1. Tenixe `claude-haiku-5-5` (ผู้ต้องสงสัย)
2. Anthropic `claude-haiku-5-5` (ของแท้แน่นอน ใช้เป็นตัวอ้างอิง)
3. Kob AI `anthropic/claude-haiku-5.5` (ของเรา ต้องใส่ `REF_OPENAI_KEY` = Token Key ของ Kob AI)

```
npm run compare                         ← prompt ตั้งต้น (ไทย/โค้ด/emoji + ถามตัวตน)
npm run compare -- "ข้อความของคุณ"       ← prompt ของคุณเอง
```
หรือเขียน prompt ไว้ในไฟล์ `prompt.txt` ผลจะเปิดในเบราว์เซอร์เป็น 3 คอลัมน์ (`results/compare-<เวลา>.html`)

วิธีตัดสิน: นับ token ของ prompt ลบด้วย token ของคำว่า "Hello" (หักส่วนที่แต่ละระบบเติมเอง)
แล้วเทียบกับ Claude ตัวจริง (`count_tokens` ของ Anthropic) และ Nemotron
ฝั่ง Kob AI จะยิง 2 ครั้ง (prompt + "Hello") ใช้ประมาณ 0.4 เครดิตต่อรอบ

## การอ่านผล
| ผล | ความหมาย |
|---|---|
| ❌ ไม่ใช่ Claude | tokenizer ตรงกับ Nemotron ทุกข้อ แต่ไม่ตรงกับ Claude ตัวจริง |
| ✅ น่าจะเป็น Claude จริง | tokenizer ตรงกับ Claude ตัวจริงทุกข้อ |
| ⚠️ ยังสรุปไม่ได้ | ยังไม่ได้ใส่ตัวอ้างอิง หรือผลออกมาก้ำกึ่ง |

ส่วน "ถามตัวตน" เป็นหลักฐานเสริมเท่านั้น โมเดลตอบตัวตนผิดได้

## ความปลอดภัย / ค่าใช้จ่าย
- ฝั่ง Tenixe ใช้เฉพาะโมเดลฟรี สคริปต์เช็คยอดใช้จ่ายหลังยิงครั้งแรก ถ้าโดนหักเงินจะ**หยุดทันที**
- `count_tokens` ของ Anthropic ไม่ได้ให้โมเดลตอบ ส่วนการถามตัวตนกับ Claude ตัวจริงเสียเงินเล็กน้อย
  (ตั้ง `ASK_REFERENCE_IDENTITY=0` ถ้าไม่อยากถาม)
- `.env` และ `results/` อยู่ใน `.gitignore` แล้ว อย่าส่งไฟล์ `.env` ให้ใคร
