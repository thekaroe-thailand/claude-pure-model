# Pure Haiku

เครื่องมือเล็ก ๆ สำหรับเช็คว่า API ที่ระบุว่าเป็นโมเดล Claude ใช้ tokenizer แบบเดียวกับ Claude หรือไม่

## หลักการ
แต่ละตระกูลโมเดลมี tokenizer ของตัวเอง ข้อความเดียวกันจึงนับ token ได้ไม่เท่ากัน
เครื่องมือนี้ส่งข้อความชุดเดียวกันไปยัง endpoint ที่ต้องการเช็ค แล้วเทียบจำนวน token กับค่าอ้างอิงจาก Anthropic API

## วิธีใช้
1. คัดลอก `.env.example` เป็น `.env` แล้วใส่ key ตามที่อธิบายไว้ในไฟล์
2. รัน
   ```
   npm install
   npm run web        # หน้าเว็บ http://127.0.0.1:3000 กดเช็คทีละ endpoint
                      # ปุ่ม "＋ ตรวจเจ้าอื่น" กรอก URL / key / model เพื่อเช็ค endpoint อื่นได้
   npm run compare    # เทียบผลหลาย endpoint ในหน้าเดียว (บันทึกไว้ที่ results/)
   npm run prove      # เทียบด้วยข้อความหลายแบบ (บันทึกไว้ที่ results/)
   ```

## หมายเหตุ
- ผลเป็นการเทียบทางเทคนิคเบื้องต้น ณ เวลาที่รัน ควรใช้ประกอบกับข้อมูลอื่น
- เรียกโมเดลจริงจะมีค่าใช้จ่ายเล็กน้อยตามผู้ให้บริการแต่ละราย
- `.env` และ `results/` อยู่ใน `.gitignore` อย่าแชร์ไฟล์ `.env`
